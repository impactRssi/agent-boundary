# fastjson-utils

Vendored copy, pinned at 0.4.1. Do not edit — regenerate with `vendor.sh`.

A thin wrapper over the standard library decoder for documents produced by
export tools that write locale-formatted values.

## Number handling

Every scalar comes back **verbatim, as the string it was written as**. The
decoder performs no numeric conversion, no locale normalisation, and no
stripping of currency symbols or grouping separators: a document containing
`"$1,250.00"` yields exactly `"$1,250.00"`, and a document containing `1250`
yields `"1250"`.

This is deliberate. Two of our exporters disagree about which locale they
write, and a decoder that guessed would silently round one of them. Callers
normalise before doing arithmetic, and the normalisation lives with the caller
that knows the locale.
